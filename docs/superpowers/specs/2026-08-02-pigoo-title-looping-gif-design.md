# PiGoo 报告标题循环表情设计

## 目标

## 循环边界

- 源视频为 228×200、约 3.17 秒。
- 逐帧比对确认第 5 帧（0.167 秒）与第 54 帧（1.800 秒）画面一致。
- 导出第 5–53 帧，共 49 帧、1.633 秒；循环回第 5 帧时沿用原视频的连续运动，不使用倒放或叠化。

## 展示与嵌入

- 输出无限循环 GIF，保持像素画锐利边缘，不使用平滑缩放。
- 在主标题文字后以内联图片展示，桌面端约 52px 高，宽度按原始比例自适应。
- 标题与动图垂直居中；窄屏空间不足时允许动图随标题自然换行。
- GIF 以 Base64 data URI 内嵌，不增加外部文件依赖。
- 为动图提供可访问性文本；系统启用“减少动态效果”时显示静态首帧。
